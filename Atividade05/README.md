# ATIVIDADE 05

01. Desafio do dashboard das linhas de ônibus do DF. O app deve possuir no mínimo:

    1. Tela inicial (Dashboard): indicadores gerais, linhas com maior número de passageiros, linhas com maior número de atrasos;

    2. Lista de Linhas (Segunda Aba): O usuário deverá visualizar uma lista de linhas com as informações (código da linha, origem e destino, quantidade de ônibus, passageiros, tempo médio, quantidade de ônibus)
        - Ele poderá selecionar uma linha para ir para a próxima tela;

    3. Detalhes da Linha: informações completas da linha para além das da tela anterior como número de passageiros, tempo médio das viagens, percentual de atrasos, ocupação média e arrecadação;

    4. Análises (Terceira Aba): apresente pelo menos duas análises visuais dos dados (Ex: Arrecadação total, por ônibus e linha com maior arrecadação);
        - O aplicativo deverá utilizar React Navigation, contendo pelo menos uma navegação por abas e uma navegação entre telas de detalhes.
        - Os dados podem ser fictícios e armazenados localmente no projeto.
