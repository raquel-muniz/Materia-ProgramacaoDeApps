# ATIVIDADE 04

Pesquisem sobre o useContext, useMemo e useCallback;
Vocês vão construir um app simples de lista de compras onde o usuário pode:
Fazer "login" com um nome;
Adicionar itens à lista;
Marcar itens como comprados;
Filtrar/buscar itens;
Ver o total de itens pendentes;
O objetivo não é a complexidade do app, e sim usar corretamente cada Hook na situação certa.
